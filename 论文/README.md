1.1 问题背景
如今，“双碳”目标和能源绿色低碳转型持续推进，光伏等分布式新能源快速发展，其高比例接入对电力系统的调节能力和新能源本地消纳提出了更高要求。微网通过协调分布式电源、储能设备与用户负荷，可以提升新能源就地利用水平并增强配用电系统的运行灵活性。《加快构建新型电力系统行动方案（2024—2027年）》提出推进智能微电网建设，提升分布式新能源的接入消纳和系统调节能力[1]，进一步体现了微网在新型电力系统建设中的重要作用。
与此同时，电价机制正逐渐成为引导用户优化用能行为、实现削峰填谷的重要手段[2]。在此背景下，微网可以根据电价变化协调本地光伏、用电负荷、储能与外部电网之间的能量交换，在保障供电需求的同时降低购电成本。然而，光伏出力和居民负荷具有明显的时变特征，预测误差与电价波动使供需匹配更具不确定性；储能容量和充放电能力的限制又使不同时段的购电决策相互关联。因此，如何充分利用预测信息与电价信号，合理协调外网购电和储能充放电，是提升微网运行经济性与灵活性的关键问题。

4.2 基于词典序优化的两阶段LP模型的建立
由问题分析可知，各时段的电价、小区负载功率和光伏发电预测功率均为已知的确定性输入，购电功率、储能充放电功率及储电量均为连续变量。同时，购电费用、功率平衡关系、储电量递推关系及各变量的上下界均可用线性函数表示。因此，问题一属于带时序耦合约束的确定性线性优化问题。
附件1将一天划分为144个长度相同的时段，每个时段为10 min，模型规模较小，可采用线性规划方法快速获得全局最优解。然而，若仅以购电费用最小为目标建立单阶段线性规划模型，则当多个调度方案具有相同购电费用时，求解器只需返回其中任意一个最优解，可能出现储能在同一时段内同时充电和放电，或发生不必要能量循环的情况。这类方案虽然可能不改变最优购电费用，但增加了储能的能量吞吐量和运行损耗，其物理意义和实际可执行性较弱。
为此，本节首先建立基于词典序优化的两阶段LP模型。第一阶段以全天购电费用最小为首要目标；第二阶段在第一阶段最优购电费用的10⁻⁴元容差内进一步最小化储能的充放电总量。该方法不需要设置主、次目标之间的主观权重，能够保持购电费用目标的首要优先级，并在极小成本容差内进一步筛选充放电行为更加简洁的调度方案。
为验证连续LP是否足以刻画储能调度过程，本节进一步构造加入充、放电互斥0-1变量的MILP对照模型。结果表明，两种模型的第一阶段最优目标值一致，MILP求解间隙为0，且LP解中未出现同一时段同时充、放电的情况。因此，本节最终采用连续LP作为主模型，MILP仅作为结构验证。与引入0-1状态变量的混合整数线性规划相比，该模型保留了购电功率及充放电功率的连续性，全部目标函数和约束条件均为线性形式，适合对全天144个时段的微网调度问题进行精确求解。

4.2.2 约束条件
两个优化阶段的公共约束条件如下：
（1）功率平衡约束
在任意时段内，电网购电、光伏发电及储能放电共同满足小区负载、储能充电和弃光需求。因此，有
P_grid,t + P_pv,t + P_dis,t = P_load,t + P_ch,t + Wₜ    (1)
式（1）保证各时段微网内部功率严格平衡，并通过弃光变量显式表示未被负载和储能吸收的光伏富余功率，从而完整描述各时段的能量流向。
（2）储电量递推约束
考虑储能充放电效率后，相邻时段之间的储电量满足
Eₜ = Eₜ₋₁ + η_c P_ch,t Δt − (P_dis,t/η_d) Δt    (2)
其中，P_ch,tΔt 表示该时段从微网流向储能装置的电量，P_dis,tΔt 表示储能装置向微网提供的电量。式（2）中的效率系数反映了储能充放电过程中的能量损失。
（3）储电量边界约束
为保证储能装置在规定的安全范围内运行，各时段结束时的储电量应满足
1200 ≤ Eₜ ≤ 10800    (3)
（4）充放电功率约束
根据储能装置的最大充放电功率，得到
0 ≤ P_ch,t ≤ 5000    (4)
0 ≤ P_dis,t ≤ 5000    (5)
（5）始末储电量约束
题目要求0:00与24:00时储能装置的储电量相同。结合初始储电量为6000 kWh，有
E₀ = E₁₄₄ = 6000    (6)
该约束能够避免模型通过消耗储能装置的初始电量人为降低当日购电费用，使不同日之间的调度结果具有可比性。
（6）购电及弃光功率约束
由于模型不考虑向外部电网售电，购电功率应为非负数，即
P_grid,t ≥ 0    (7)
弃光功率不能超过该时段的光伏发电预测功率，因此有
0 ≤ Wₜ ≤ P_pv,t    (8)
4.2.3 第一阶段：购电费用最小化
第一阶段以全天购电费用最低为目标。在第 t 个时段内，购电功率为 P_grid,t，时段长度为 Δt，因此该时段的购电量为 P_grid,tΔt，相应购电费用为 pₜP_grid,tΔt。
在满足式（1）—式（8）的条件下，第一阶段目标函数为
min C = Σₜ₌₁¹⁴⁴ pₜ P_grid,t Δt = C*    (9)
其中，C*表示第一阶段求得的最小日购电费用。由于pₜ的单位为元/kWh，P_grid,t的单位为kW，Δt的单位为h，因此目标函数的单位为元。
通过求解式（9），可以得到使全天购电费用最低的调度方案及最优购电费用 C*。但在第一阶段最优购电费用对应的可行域中，可能存在多个购电费用相同而充放电行为不同的最优方案，因此还需进行第二阶段优化。
4.2.4 第二阶段：储能充放电总量最小化
第二阶段保持式（1）—式（8）的全部约束不变，并将第一阶段求得的最优购电费用约束为不超过 C*+10⁻⁴，即
Σₜ₌₁¹⁴⁴ pₜ P_grid,t Δt ≤ C* + 10⁻⁴    (10)
为避免第一阶段经济最优解存在多解时产生不必要的充放电行为，第二阶段在第一阶段最优购电费用 C* 的基础上引入人为设置的成本保持容差10⁻⁴元。该容差相对于约3.5×10⁴元的日购电费用仅为10⁻⁹量级，不会造成具有实际意义的经济损失，从而可以从近似等价的经济最优轨迹中选择充放电行为更简洁的方案。
在此基础上，以全天储能充放电总量最小为第二阶段目标：
min Q = Σₜ₌₁¹⁴⁴ (P_ch,t + P_dis,t) Δt = Q*    (11)
其中，Q*表示在购电费用不超过 C*+10⁻⁴ 的前提下，储能装置最小的充放电总量，单位为kWh。
4.3 模型的求解
词典序两阶段LP模型的具体求解流程如下：
Step1，将附件1中的电价、小区负载功率和光伏发电预测功率作为已知参数输入模型，在式（1）—式（8）的约束下求解式（9），得到全天最小购电费用 C*。
Step2，将第一阶段得到的 C* 代入式（10），在购电费用不超过 C*+10⁻⁴ 的前提下求解式（11），得到储能充放电总量最小的最终调度方案。
Step3，为与求解程序及结果文件中的槽能量口径保持一致，记
gₜ = P_grid,t Δt，  cₜ = P_ch,t Δt，  dₜ = P_dis,t Δt，  uₜ = Wₜ Δt    (12)
其中，gₜ、cₜ、dₜ、uₜ分别表示第t个10 min时段的购电量、储能充电量、储能放电量和弃光量，单位均为kWh。由于Δt=1/6 h，附件中的功率数据转换为单个时段电量时均需乘以1/6；最大充、放电功率5000 kW对应单个时段的能量上限为5000/6 kWh。
最终，求得问题一结果如下：无储能基准购电费用约为48052.05元，采用储能优化后，第二阶段最终调度方案的购电费用约为35126.95元，相较无储能基准降低约26.90%。运行过程中储能装置的储电量始终处于1200～10800 kWh的安全运行区间，且0:00与24:00的储电量均为6000 kWh，符合题目要求。完整购电策略见result1.xlsx。
