1.1 问题背景
如今，“双碳”目标和能源绿色低碳转型持续推进，光伏等分布式新能源快速发展，其高比例接入对电力系统的调节能力和新能源本地消纳提出了更高要求。微网通过协调分布式电源、储能设备与用户负荷，可以提升新能源就地利用水平并增强配用电系统的运行灵活性。《加快构建新型电力系统行动方案（2024—2027年）》提出推进智能微电网建设，提升分布式新能源的接入消纳和系统调节能力[1]，进一步体现了微网在新型电力系统建设中的重要作用。
与此同时，电价机制正逐渐成为引导用户优化用能行为、实现削峰填谷的重要手段[2]。在此背景下，微网可以根据电价变化协调本地光伏、用电负荷、储能与外部电网之间的能量交换，在保障供电需求的同时降低购电成本。然而，光伏出力和居民负荷具有明显的时变特征，预测误差与电价波动使供需匹配更具不确定性；储能容量和充放电能力的限制又使不同时段的购电决策相互关联。因此，如何充分利用预测信息与电价信号，合理协调外网购电和储能充放电，是提升微网运行经济性与灵活性的关键问题。

4.2 基于词典序优化的两阶段LP模型的建立
由问题分析可知，各时段的电价、小区负载功率和光伏预测功率均为已知的确定性输入，购电功率、储能充放电功率及储电量均为连续变量。同时，购电费用、功率平衡关系、储电量递推关系及各变量的上下界均可用线性函数表示。因此，问题一属于带时序耦合约束的确定性线性优化问题。
附件1将一天划分为144个长度相同的时段，每个时段为10 min，模型规模较小，可采用线性规划方法快速获得全局最优解。然而，若仅以购电费用最小为目标建立单阶段线性规划模型，则当多个调度方案具有相同购电费用时，求解器只需返回其中任意一个最优解，可能出现储能在同一时段内同时充电和放电，或发生不必要能量循环的情况。这类方案虽然可能不改变最优购电费用，但增加了储能的能量吞吐量和运行损耗，其物理意义和实际可执行性较弱。
为此，本文建立基于词典序优化的两阶段LP模型。第一阶段以全天购电费用最小为首要目标；第二阶段在保持第一阶段最优购电费用不变的条件下，进一步最小化储能的充放电总量。该方法不需要设置主、次目标之间的主观权重，能够保证购电费用目标具有绝对优先级，并从购电费用相同的多个最优方案中筛选出充放电行为更加简洁的调度方案。与引入0-1状态变量的混合整数线性规划相比，该模型保留了购电量及充放电量的连续性，全部目标函数和约束条件均为线性形式，适合对全天144个时段的微网调度问题进行精确求解。

4.2.2 公共约束条件
两个优化阶段采用相同的可行域，其公共约束条件如下。
（1）功率平衡约束
在任意时段内，电网购电、光伏发电及储能放电共同满足小区负载、储能充电和弃光需求。因此，有
Gt+Rt+Ptdis=Lt+Ptch+Wt,t=1,2,…,T.(1)G_t+R_t+P_t^{\mathrm{dis}} =L_t+P_t^{\mathrm{ch}}+W_t, \qquad t=1,2,\ldots,T. \tag{1}
式（1）能够保证微网的供电功率不低于小区负载功率，并通过弃光变量对光伏富余电量进行显式处理，使各时段的能量流向保持完整。
（2）储电量递推约束
考虑储能充放电效率后，相邻时段之间的储电量满足
Et=Et−1+ηchPtchΔt−PtdisηdisΔt,t=1,2,…,T.(2)E_t =E_{t-1} +\eta_{\mathrm{ch}}P_t^{\mathrm{ch}}\Delta t -\frac{P_t^{\mathrm{dis}}}{\eta_{\mathrm{dis}}}\Delta t, \qquad t=1,2,\ldots,T. \tag{2}
其中，PtchΔtP_t^{\mathrm{ch}}\Delta t 表示该时段从微网流向储能装置的电量，PtdisΔtP_t^{\mathrm{dis}}\Delta t 表示储能装置向微网提供的电量。式（2）中的效率系数反映了储能充放电过程中的能量损失。
（3）储电量边界约束
为保证储能装置在规定的安全范围内运行，各时段结束时的储电量应满足
1200≤Et≤10800,t=1,2,…,T.(3)1200\leq E_t\leq10800, \qquad t=1,2,\ldots,T. \tag{3}
（4）充放电功率约束
根据储能装置的最大充放电功率，得到
0≤Ptch≤5000,t=1,2,…,T,(4)0\leq P_t^{\mathrm{ch}}\leq5000, \qquad t=1,2,\ldots,T, \tag{4} 0≤Ptdis≤5000,t=1,2,…,T.(5)0\leq P_t^{\mathrm{dis}}\leq5000, \qquad t=1,2,\ldots,T. \tag{5}
（5）始末储电量约束
题目要求0:00与24:00时储能装置的储电量相同。结合初始储电量为 6000 kWh6000\ \mathrm{kWh}，有
E0=ET=6000.(6)E_0=E_T=6000. \tag{6}
该约束能够避免模型通过消耗储能装置的初始电量人为降低当日购电费用，使不同日之间的调度结果具有可比性。
（6）购电及弃光功率约束
由于模型不考虑向外部电网售电，购电功率应为非负数，即
Gt≥0,t=1,2,…,T.(7)G_t\geq0, \qquad t=1,2,\ldots,T. \tag{7}
弃光功率不能超过该时段的光伏预测功率，因此有
0≤Wt≤Rt,t=1,2,…,T.(8)0\leq W_t\leq R_t, \qquad t=1,2,\ldots,T. \tag{8}
4.2.3 第一阶段：购电费用最小化
第一阶段以全天购电费用最低为目标。在第 tt 个时段内，购电功率为 GtG_t，时段长度为 Δt\Delta t，因此该时段的购电量为 GtΔtG_t\Delta t，相应购电费用为 ptGtΔtp_tG_t\Delta t。
在满足式（1）—式（8）的条件下，第一阶段目标函数为
C∗=min⁡∑t=1TptGtΔt.(9)C^{*} = \min \sum_{t=1}^{T}p_tG_t\Delta t. \tag{9}
其中，C∗C^{*} 表示第一阶段求得的最小日购电费用。由于 ptp_t 的单位为元/kWh，GtG_t 的单位为kW，Δt\Delta t 的单位为h，因此目标函数的单位为元。
通过求解式（9），可以得到使全天购电费用最低的调度方案及最优购电费用 C∗C^{*}。但在最优购电费用对应的可行域中，可能存在多个购电费用相同而充放电行为不同的等价最优方案，因此还需进行第二阶段优化。
4.2.4 第二阶段：储能充放电总量最小化
第二阶段保持式（1）—式（8）的全部约束不变，并将第一阶段求得的最优购电费用锁定为 C∗C^{*}，即
∑t=1TptGtΔt=C∗.(10)\sum_{t=1}^{T}p_tG_t\Delta t=C^{*}. \tag{10}
在此基础上，以全天储能充放电总量最小为第二阶段目标：
Q∗=min⁡∑t=1T(Ptch+Ptdis)Δt.(11)Q^{*} = \min\sum_{t=1}^{T} \left(P_t^{\mathrm{ch}}+P_t^{\mathrm{dis}}\right)\Delta t. \tag{11}
其中，Q∗Q^{*} 表示在购电费用达到最优值的前提下，储能装置最小的充放电总量。
第二阶段在所有购电费用为 C∗C^{*} 的方案中，优先选择储能能量吞吐量较小的方案。当某一成本等价方案中存在冗余充放电或不必要的能量循环时，其充放电总量通常更大，因此不会优先于具有相同购电费用但充放电总量更小的方案。由此可降低单阶段LP返回同期充放电等物理意义较弱方案的可能性，并提高调度结果的可解释性和实际可执行性。
需要说明的是，式（10）是理论模型中的严格等式。实际计算受到浮点运算和求解器数值精度的影响，可在求解器规定的可行性容差和最优性容差范围内锁定 C∗C^{*}，而不应随意指定缺乏依据的固定误差值。具体计算时应同时记录求解器的容差设置，并检验第二阶段所得购电费用与 C∗C^{*} 的差值，确保该差值未超过设定的数值容差。
