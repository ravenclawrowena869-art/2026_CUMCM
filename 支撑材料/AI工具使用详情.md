## 一、记录要求

每条记录至少说明：

1. AI 工具名称、版本或模型；
2. 使用目的和具体环节；
3. 主要提示方式与使用过程；
4. AI 输出中实际采纳了什么、人工修改了什么、如何核验；
5. 若 AI 输出存在错误或被否决，应如实记录关键纠正情况。

注意：不得在本文件内容、文件名或后续 PDF 中写入参赛者姓名、队伍编号、学校名、赛区等身份信息。

## 三、赛中使用记录

### 记录 01：赛题理解与附件数据初步检查

- **工具 / 模型**：ChatGPT，GPT-5.6 Sol
- **使用目的**：辅助梳理 C 题四个问题的任务关系；检查附件 Excel 的数据含义、规模、时间结构及潜在数据质量问题。
- **主要提示方式与过程**：先要求以易懂语言解释赛题，再逐个分析附件数据的数据量、时间粒度、异常值和清洗需求；对模型给出的数据解释由参赛队结合原始 Excel 人工核对。
- **采纳、修改与核验**：采纳了对四问总体逻辑和数据结构的整理。人工核对发现模型曾将附件 3 中分组显示造成的空白日期误读为数值“28”，随后明确纠正为“同组空白日期继承上方日期”，不将其作为异常数据处理。该纠正说明 AI 输出需由参赛队对照原始数据核实后使用。

### 记录 02：支撑材料合规核查与仓库结构整理

- **工具 / 模型**：ChatGPT，GPT-5.6 Sol
- **使用目的**：依据参赛须知检查电子论文与支撑材料的组织方式，并协助整理 GitHub 仓库目录。
- **主要提示方式与过程**：要求读取最新参赛须知，逐条核对支撑材料应包含的源程序、自主查阅资料、中间结果、AI 工具使用详情、压缩格式、身份信息限制等要求，再据此修改仓库说明和提交检查清单。
- **采纳、修改与核验**：参赛队人工确认采用“赛中以 Markdown 持续记录 AI 使用详情，最终人工核验后转换为规定名称的 PDF 并删除赛中 Markdown”的工作方式；最终支撑材料使用 WinRAR 压缩为 RAR 文件，并进行文件清单与身份信息复核。
