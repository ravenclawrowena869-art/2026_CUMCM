## 目录职责

- `01_源程序/`：论文模型与结果所对应的全部可运行源程序。
- `02_自主数据/`：仅放自行查阅并实际使用的数据；赛题提供的原始附件不重复放入。
- `03_中间结果/`：保存论文结论所依赖、但不适合全部放入正文的较大图表、表格和必要数值结果。
- `04_复现说明/`：运行环境、入口脚本、运行顺序、输入输出对应关系和复现步骤。

最终支撑材料文件清单必须同步写入论文附录。所有文件及其元数据不得出现参赛者姓名、学校、赛区等身份信息。
