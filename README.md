# 2026 CUMCM 提交仓库

本仓库按“参赛论文 + 支撑材料”两部分组织，目标是在比赛结束时可直接下载仓库并生成两个独立提交文件。

- `论文/`：放最终参赛论文；正式提交时上传单独 PDF，不压缩。
- `支撑材料/`：放可运行源程序、必要的自主数据、论文所引用的较大中间结果以及赛题要求的结果文件；正式提交时整体压缩为 ZIP/RAR。

## 赛中约定

1. 所有路径、文件名、代码注释、图片、文档属性中不得出现参赛者姓名、学校、赛区等身份信息。
2. 赛题提供的原始附件不重复放入支撑材料；若使用自行查阅的外部数据，则放入 `支撑材料/02_自主数据/` 并注明来源。
3. 论文引用到的正式数值必须能够追溯到 `支撑材料/01_源程序/` 与 `支撑材料/03_中间结果/` 中的实际运行结果。
4. C 题要求的 `result1.xlsx`、`result2.xlsx`、`result3.xlsx`、`result4-2.xlsx`、`result4-3.xlsx` 最终直接放在 `支撑材料/` 根目录，保持官方文件名。
5. 最终论文电子版建议为 PDF，单文件不超过 20MB；支撑材料压缩包为 ZIP/RAR，不超过 20MB。
6. 支撑材料最终文件清单应同步写入论文附录。

## 最终提交形态

```text
2026_CUMCM/
├─ 论文/
│  └─ 论文.pdf
└─ 支撑材料/
   ├─ result1.xlsx
   ├─ result2.xlsx
   ├─ result3.xlsx
   ├─ result4-2.xlsx
   ├─ result4-3.xlsx
   ├─ 01_源程序/
   ├─ 02_自主数据/
   ├─ 03_中间结果/
   └─ 04_复现说明/
```

比赛提交时：从 `论文/` 取最终 PDF；将 `支撑材料/` 整体压缩为一个 ZIP/RAR 后上传。
