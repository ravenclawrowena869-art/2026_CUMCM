# 2026 CUMCM 提交仓库

本仓库按“参赛论文 + 支撑材料”两部分组织，目标是在比赛结束时下载仓库后，只需完成最终冻结、PDF 导出和 WinRAR 压缩即可提交。

- `论文/`：存放论文工作稿及最终参赛论文；广东赛区最终电子版论文只能提交单独 PDF，不压缩。
- `支撑材料/`：存放可运行源程序、自主查阅并实际使用的数据资料、论文所依赖的较大中间结果、复现说明、AI 工具使用详情以及赛题要求的结果文件。

## 赛中约定

1. 所有路径、文件名、代码注释、图片、文档内容与文档属性中不得出现参赛者姓名、队伍编号、学校、赛区等身份信息。
2. 赛题提供的原始附件不重复放入支撑材料；若使用自行查阅的外部数据或难以从公开渠道找到的相关资料，则放入 `支撑材料/02_自主数据/` 并注明来源。
3. 论文引用到的正式数值必须能够追溯到 `支撑材料/01_源程序/` 与 `支撑材料/03_中间结果/` 中的实际运行结果。
4. 所有实际使用的源程序必须同时进入论文附录和 `支撑材料/01_源程序/`，并保证可运行且结果与论文一致。
5. C 题要求的 `result1.xlsx`、`result2.xlsx`、`result3.xlsx`、`result4-2.xlsx`、`result4-3.xlsx` 完成后直接放在 `支撑材料/` 根目录，保持官方文件名。
6. 赛中使用 `支撑材料/AI工具使用详情.md` 持续记录真实 AI 使用过程；最终人工核验后转换为官方要求的 `AI 工具使用详情.pdf`，并删除赛中 Markdown。
7. 支撑材料最终文件清单必须同步写入论文附录，并与最终 RAR 中的实际文件逐项一致。
8. 最终论文 PDF 与支撑材料 RAR 均不得超过 20MB。

## 最终提交形态

最终冻结后应整理为：

```text
论文.pdf                         # 单独提交，不压缩

支撑材料/
├─ AI 工具使用详情.pdf
├─ result1.xlsx
├─ result2.xlsx
├─ result3.xlsx
├─ result4-2.xlsx
├─ result4-3.xlsx
├─ 01_源程序/
├─ 02_自主数据/                  # 未实际使用外部资料时可删除
├─ 03_中间结果/
└─ 04_复现说明/
```

提交时不要直接把 GitHub 下载得到的 ZIP 当作支撑材料上传。应从 `论文/` 取最终 PDF；对 `支撑材料/` 完成最终清理后，使用通用 **WinRAR** 压缩为 **RAR** 文件再上传。

最终操作按根目录 `FINAL_SUBMISSION_CHECKLIST.md` 逐项复核。
